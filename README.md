# Kompresija i zastita podataka

Repozitorijum sadrzi dva projektna zadatka uradjena u Pythonu.

- `Projekat1` - entropija, Shannon-Fano, Huffman, LZ77 i LZW algoritmi.
- `Projekat2` - LDPC kod, sindromsko dekodiranje i Gallager B algoritam.

Pokretanje:

Za Projekat1 opisano u Projekat1/report.txt fajlu detaljno za svaki algoritam. Ovde je prikazan jedan primer pokretanja.

```powershell
py Projekat1/main.py entropy Projekat1/sample.txt
py Projekat2/ldpc.py
```
